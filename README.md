# MCM2026ProblemB
Github Repo for Question B Mathematical Modeling Contest (MCM) of 2026. 

The problem statement involves optimizing Earth-Lunar logistics to build a lunar base, with a hypothetical space elevator design. Our team used MILP and Monte Carlo methods to build our main model, along with backup research on minimizing space elevator tensor swings, lunar base water usage, and Earth environmental impacts. We developed an optimized hybrid logistic schedule using both tranditional rocket delivery and space elevator.

Distinction: Finalist & MAA Awards.
